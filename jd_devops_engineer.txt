We are looking for a DevOps / Cloud Engineer to help us build and maintain our cloud infrastructure and deployment pipelines.

ABOUT THE ROLE:
You will be responsible for managing cloud infrastructure, automating deployments, and ensuring high availability of our services on AWS.

RESPONSIBILITIES:
- Design, build and maintain CI/CD pipelines using Jenkins or GitHub Actions
- Manage containerized applications using Docker and Kubernetes
- Provision and manage cloud infrastructure using Terraform and Ansible
- Monitor system performance using Prometheus and Grafana
- Ensure security best practices across all infrastructure
- Automate repetitive tasks using Bash and Python scripts
- Collaborate with development teams to improve deployment processes

REQUIRED SKILLS:
- Cloud: AWS (EC2, S3, RDS, Lambda, EKS)
- Containers: Docker, Kubernetes
- CI/CD: Jenkins, GitHub Actions or GitLab CI
- IaC: Terraform
- Scripting: Bash, Python
- OS: Linux
- Version Control: Git

GOOD TO HAVE:
- Azure or Google Cloud experience
- Ansible or Chef or Puppet
- ELK Stack (Elasticsearch, Logstash, Kibana)
- Helm charts
- AWS certifications

EDUCATION:
- B.Tech or B.E. in Computer Science, IT or related field

EXPERIENCE:
- 1-3 years of experience in DevOps or cloud infrastructure
- Hands-on experience with AWS is mandatory

SOFT SKILLS:
- Problem solving under pressure
- Strong communication skills
- Proactive and self-motivated
